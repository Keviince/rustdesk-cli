# v0.1.4 — Reliable Windows commands and clean batch output

Windows one-shot commands now wait for an explicit completion record and report the remote command's exit status. Long downloads and installations no longer finish early because output pauses. `--command-timeout` controls execution separately from connection setup, and established terminal sessions no longer inherit the setup deadline.

One-shot output hides startup echoes and internal records, removes remote cursor and screen-clearing instructions, suppresses PowerShell progress bars, and normalizes line endings. The batch helper preserves output order, removes extra blank separators and keeps device results on separate lines.

The release includes the sequential NetBird upgrade helper. It supports a device/password file, connection checks with `--check`, individual device results and a final summary. It continues after individual failures without retrying devices.

Assets:

- Linux and macOS binaries for amd64 and arm64.
- `netbird-upgrade.sh` and `devices.example.txt`.
- `checksums.txt` for the binaries.

For Linux, download the matching binary, rename it to `rdcli`, and put it beside the helper:

```bash
chmod +x rdcli netbird-upgrade.sh
chmod 600 devices.txt
./netbird-upgrade.sh --check --file devices.txt
./netbird-upgrade.sh --file devices.txt
```

Each device file line contains a numeric RustDesk ID followed by whitespace and the device access password. Replace the example password before use; passwords are literal and must not be shell-quoted. The helper reuses saved API login and server settings and forces relay connections.

Windows users can build from source:

```powershell
go build -trimpath -o rdcli.exe ./cmd/rdcli
```

Build, test and vet checks cover Linux, macOS and Windows. Linux checks also exercise the helper with a fake client; no installer runs during these tests.

# v0.1.3 — Windows shell Enter fix

Fix one-shot `rdcli sh` commands that were not submitted on Windows remote terminals. Commands now end with a carriage return (`\r`), matching the Enter key, instead of a newline (`\n`).

```sh
rdcli -c home-pc sh "whoami"
```

The release includes Linux/macOS binaries for amd64 and arm64, plus `checksums.txt`. Windows users can build from source:

```powershell
go build -trimpath -o rdcli.exe ./cmd/rdcli
```
